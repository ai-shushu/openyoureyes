# Open Your Eyes · 让闲置手机当 AI 智能体的眼睛

把旧手机架在工作台上，AI 智能体需要看实物（电路板、接线、屏幕、零件）时，手机立即拍照交给它。目前支持 Claude 桌面版、Claude Code、Codex 和 WorkBuddy。

- **手机扫码就能用**：浏览器打开即可，安卓也可以装一个小 App（熄屏也能待命）。可以放好几台手机，从不同角度同时拍。
- **每张照片都要你允许**：AI 想拍照时，会先在对话里问你。你不点允许，手机不会拍。
- **全部在你自己的电脑和 Wi-Fi 里完成**：照片只存在这台电脑上，不经过任何服务器，没有账号，不收集数据。

## 三步开始

### 1. 电脑：安装 Open Your Eyes
- **Mac**（Apple 芯片和 Intel 芯片都可以，macOS 11 及以上）：从 [Releases 页面](https://github.com/ai-shushu/openyoureyes/releases/latest) 下载 `OpenYourEyes-版本号-mac.dmg`，打开后把 Open Your Eyes 拖进「应用程序」，再双击打开。
- 第一次打开如果提示「无法打开」「无法验证开发者」或「已损坏」：这是因为还没有向苹果付费签名，不是病毒。打开「终端」，粘贴下面这行并回车，输入开机密码（输入时不显示）后再打开即可：
  ```
  sudo xattr -rd com.apple.quarantine "/Applications/Open Your Eyes.app"
  ```
  不想用终端：被拦一次后，去「系统设置 → 隐私与安全性」，拉到最下面点「仍要打开」。
- 第一次打开会问「是否允许查找本地网络上的设备」，请点**允许**，否则手机连不上。
- 打开后会出现 Open Your Eyes 窗口，菜单栏也有一个眼睛图标。关掉窗口程序仍在后台运行；从菜单栏图标或再次打开程序就能找回窗口。

### 2. 连接 AI：一键安装
在 Open Your Eyes 窗口右边的「连接 AI」里，电脑上装了的 AI 会自动列出来，点「一键安装」就行：
- **Claude 桌面版**：会弹出安装扩展的界面，点「安装」。
- **Claude Code**、**Codex**：直接装好。
- **WorkBuddy**：装好后在 WorkBuddy 的「连接 → 自定义连接」里点一次「信任」。

装好后要**新开一个对话**才生效（Claude 桌面版要重启一次）。

### 3. 手机：扫码加入
在窗口里点「＋ 添加机位」，用手机相机扫码，按手机上的提示操作：
- **安卓**：推荐装 App（扫码后的页面里点「下载并安装 App」），熄屏也能待命，不用装证书。
- **iPhone**：用 Safari 打开，按教程信任一次证书。拍照页要保持在前台。

把手机架好、插上充电器，就可以了。

## 怎么让 AI 用手机看
对 AI 说「**睁眼**」，比如「睁眼看看这块板子」「睁眼，桌上有什么」，它就会用手机拍照（拍之前会先问你）。
想百分之百确定：在 Claude Code 里输入 `/` 选「用手机拍一张」，Claude 桌面版在输入框的「+」菜单里找。

手动接入其它 AI：本机接口是 `http://127.0.0.1:39757/mcp`（Streamable HTTP），Claude Code 也可以用插件市场安装：`/plugin marketplace add ai-shushu/openyoureyes`，然后 `/plugin install open-your-eyes@open-your-eyes`。

## 常见问题

**扫码后打不开页面？**
手机和电脑必须连同一个 Wi-Fi。很多路由器的「访客网络」会把设备互相隔开，请连主网络。

**手机显示「等电脑允许」？**
在电脑设置页里，这台手机下面点「允许」。扫设置页二维码加入的手机会自动通过。

**提示「不信任证书」/ 拍照页打不开摄像头？**
网页要用摄像头，必须是加密连接，所以第一次需要在手机上信任 Open Your Eyes 的证书。按扫码后的教程操作；iPhone 最后一步是「设置 → 通用 → 关于本机 → 证书信任设置」里打开开关。
这个证书只能用于你家局域网里的地址，不能冒充任何网站。

**安卓要不要装 App？**
不装也能用（网页）。装了更省心：不用装证书，**熄屏也能待命**，手机重启后自动连回电脑。扫码后的页面里点「下载并安装 App」，再点「用 App 连接」即可。安装包直接从你的电脑下载，不经过任何服务器；有的手机会提示「非应用商店来源」，允许这一次即可。
熄屏后掉线的话，在 App 里点「允许后台运行」和「自启动设置」：App 会按你的手机品牌（小米、华为、荣耀、OPPO、一加、vivo、三星、魅族）直接打开对应的设置页，并写出要打开哪几个开关。

**电脑换了 Wi-Fi / 地址变了？**
安卓 App 和开着的网页拍照页会自己在同一个 Wi-Fi 里找回电脑，不用重新扫码。网页被关掉了的话，重新扫一次码即可。

**怎么更新？**
有新版本时，Open Your Eyes 窗口顶部会提示，点「去下载」，下载后拖进「应用程序」替换旧版；配对过的手机和设置都会保留。手机 App 会在 App 里提示「电脑上有新版本」，点一下就更新。

**安卓用哪个浏览器？**
- **Chrome**：最稳，按教程装一次证书即可。
- **vivo 浏览器**：可以用。它不认手机里装的证书，所以不用装；打开拍照页时弹出「网站安全证书来自未知授权中心」，确认网址是你电脑的地址后点「继续浏览」，浏览器会记住。
- **部分手机自带浏览器**（实测美图）：不让网页用摄像头，用不了，请装 Chrome。扫码后页面会自动提示。
- 微信、QQ 里打开的页面也用不了摄像头，请点右上角「⋯」在浏览器中打开。

**手机一会儿就离线？**
拍照页要保持在前台、屏幕常亮（页面会自动阻止熄屏）。建议插着充电器。有手机在线时，Open Your Eyes 会阻止电脑自动睡眠。

**电脑开了 VPN / 装了虚拟机，手机连不上？**
设置页「诊断」里可以手动选「手机连电脑用」的网卡。

**出问题了怎么办？**
菜单栏图标 →「导出诊断」，或设置页「诊断 → 导出诊断」，把生成的压缩包发给开发者。里面只有运行记录，不含照片。

## 开发

```
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pyinstaller
./eyes.sh up                      # 后台启动（菜单栏出现图标），设置页 http://127.0.0.1:39757/settings
.venv/bin/python -m unittest discover -s tests -v
```
