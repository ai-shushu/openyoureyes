# Open Your Eyes

**让闲置手机（或电脑摄像头）当 AI 的眼睛。**

AI 写代码、查问题时看不到你桌上的实物。把一台旧手机架在工作台上，对 AI 说「**睁眼，看看这块板子**」，屏幕中间弹出取景器，你按一下回车，照片就交到 AI 手里。

支持 **Claude 桌面版、Claude Code、Codex、WorkBuddy**。

- **装一个程序就能用**：电脑装 Open Your Eyes，AI 在程序里一键接好；手机扫码加入，不用注册、不用改配置。
- **拍什么你说了算**：AI 要拍照时先弹出取景器，你看着实时画面摆好再按回车；Esc 就是不拍。
- **几台一起拍**：可以放好几台手机，从俯视、侧面等不同角度同时拍；电脑自带的摄像头、USB 摄像头也能当机位。
- **全部在本地**：照片只存在你的电脑上，手机和电脑在你家 Wi-Fi 里直连，不经过任何服务器，没有账号，不收集数据。

## 安装

### 电脑

| 系统 | 怎么装 |
|---|---|
| **Mac**（macOS 11 及以上，Apple 芯片和 Intel 都可以） | 从 [Releases](https://github.com/ai-shushu/openyoureyes/releases/latest) 下载 `OpenYourEyes-版本号-mac.dmg`，把 Open Your Eyes 拖进「应用程序」，双击打开 |
| Windows / Linux | 暂未提供安装包（代码按跨平台编写，还没在这两个系统上完整测试过） |

第一次打开时：

- **提示「无法打开」或「无法验证开发者」**：目前还没有苹果开发者签名，不是病毒。去「系统设置 → 隐私与安全性」，拉到最下面点「仍要打开」。
- **问「是否允许查找本地网络上的设备」**：点**允许**，否则手机连不上电脑。

打开后会出现 Open Your Eyes 窗口，菜单栏也有一个眼睛图标。关掉窗口程序仍在后台；点菜单栏图标或再次打开程序就能找回窗口。默认开机自动启动。

### 连接 AI

窗口右边「连接 AI」会列出这台电脑上装了的 AI，点「**一键安装**」：

- **Claude 桌面版**：弹出扩展安装界面，点「安装」，然后重启 Claude 桌面版。
- **Claude Code、Codex**：直接装好，新开一个对话就能用。
- **WorkBuddy**：装好后在 WorkBuddy 的「连接 → 自定义连接」里点一次「信任」。

开着 VPN、代理软件也能用：AI 连 Open Your Eyes 走本机直连，不经过代理。

### 加机位

在窗口里点「**＋ 添加机位**」：

- **安卓手机**：用手机相机扫码，点「下载并安装 App」。装好后熄屏也能待命，手机重启后自动连回电脑。
- **iPhone**：用 Safari 扫码打开，按页面教程信任一次证书。iPhone 用的是网页，拍照页要一直开着、屏幕常亮。
- **电脑摄像头**：二维码下面点「用『摄像头名字』」。第一次 Mac 会问能不能用摄像头，点「允许」。摄像头平时关着，只在拍照、取景时打开。

手机和电脑要连**同一个 Wi-Fi**（别用访客网络）。把手机架好、插上充电器就行。

## 使用

对 AI 说「**睁眼**」，后面跟你想让它看的东西：

> 睁眼，看看这块板子的接线
> 睁眼，用俯拍和侧拍两台一起看

- 屏幕中间会弹出**取景器**，显示要用的机位的实时画面。摆好后按**回车**拍照，按 **Esc** 取消；多台时点一下某个画面，这次就不用它。
- 默认所有在线机位同时拍。说出机位名，AI 就只用那几台。机位名可以在窗口里点名字修改。
- 机位固定好以后，可以在窗口里关掉「拍照前先取景」，AI 就直接拍。
- AI 还能放大刚拍的照片局部（不用重拍），或者连拍几帧看正在变化的东西（指示灯闪烁、屏幕刷新）。

更完整的说明（每种手机的设置、省电、更新、常见问题）都在程序窗口顶部的「**使用帮助**」里。

## 常见问题

**手机扫码后打不开页面？**
确认手机和电脑连的是同一个 Wi-Fi。很多路由器的访客网络会把设备隔开。

**安卓手机熄屏后掉线？**
在 App 里点「允许后台运行」和「自启动设置」，App 会按你的手机品牌打开对应的设置页，并写明要打开哪几个开关。

**iPhone 一会儿就离线？**
拍照页必须在前台：设置 → 显示与亮度 → 自动锁定 → 永不，并关掉低电量模式。

**说了「睁眼」AI 没反应？**
确认窗口里「连接 AI」显示「已就绪」，然后新开一个对话再说（Claude 桌面版要先重启）。

**出问题了怎么反馈？**
窗口里「诊断 → 导出」，把生成的压缩包发给开发者。里面只有运行记录，不含照片。

## 隐私

照片只在你的电脑上，手机只和你扫码配对的那台电脑通信。唯一的对外联网是每 12 小时检查一次有没有新版本。详见 [PRIVACY.md](PRIVACY.md)。

## 开发

电脑端是 Python，全部本地运行；安卓 App 是不依赖第三方库的原生 Java。

```
server/      页面服务、拍照调度、MCP 接口（serve.py）、电脑摄像头（localcam.py）、各 AI 接入（integrations.py）
app/         桌面程序：菜单栏图标、程序窗口、取景器窗口、守护页面服务
web/         设置页、手机拍照页、取景器、证书教程页
android/     安卓 App
desktop-extension/  Claude 桌面版扩展（Node，无依赖）
plugin/      Claude Code 插件
tests/       端到端测试
dev/         打包和开发工具（不进入用户流程）
```

从源码运行（目前只在 Mac 上测试过）：

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app/openyoureyes.py          # 设置页 http://127.0.0.1:39757/settings
.venv/bin/python -m unittest discover -s tests # 跑测试
```

打包和发布流程见 [docs/发布.md](docs/发布.md)。
